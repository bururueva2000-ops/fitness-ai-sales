# AI-фитнес консультант

Одностраничный русскоязычный чат на React + Vinext. Серверный POST `/api/chat` обращается к Google Gemini REST API. Ключ не передаётся в браузер. Автоматическое приветствие задано локально; дальнейшие ответы генерирует Gemini, демонстрационных ответов нет.

## Запуск

Нужны Node.js 22.13+ и npm. В корне проекта:

```sh
npm run install:ci
cp .env.example .env
# Укажите свой GEMINI_API_KEY в .env
npm run dev
```

В Windows для копирования: `Copy-Item .env.example .env`. Откройте адрес, который покажет сервер (обычно http://localhost:5173).

Если локальная среда Cloudflare не запускается в Windows, используйте `npm run dev:node`: он запускает тот же интерфейс и API в Node.js и читает ключ из `.env`. Публикация по-прежнему использует Cloudflare Worker.

Сборка: `npm run build`. Запуск собранной версии: `npm start`. Для локального Wrangler секрет можно задать в `.dev.vars` в формате `GEMINI_API_KEY=...`. Для публикации в Sites укажите `GEMINI_API_KEY` как секрет среды сайта и выполните повторную публикацию. Не добавляйте ключ в `.openai/hosting.json`, frontend или Git. `.env*` и `.dev.vars*` исключены из Git, кроме `.env.example`.

## Настройка

- `lib/product.ts`: описание, состав, цена `priceRub`, ссылка `PURCHASE_URL`. Сейчас цена 4 990 ₽, покупка ведёт на тестовый `https://example.com/buy` и не принимает оплату.
- `lib/system-prompt.ts`: отдельный системный промпт, этапы продаж, персонализация, возражения, правила неизвестных фактов и медицинских ограничений.
- `lib/chat-shared.ts`: первое приветствие.
- `GEMINI_MODEL`: модель, по умолчанию `gemini-3.6-flash`. Можно заменить на доступную вашему аккаунту модель с поддержкой JSON schema.

Клиент отправляет весь текущий диалог. Он хранится только в памяти вкладки: обновление страницы или «Начать заново» очищает историю. Запрос при сбросе отменяется на клиенте, его запоздалый ответ игнорируется. Лимиты: сообщение 4 000 символов, до 50 обращений к модели в одном диалоге, тело запроса 120 КБ, ожидание Gemini 45 секунд. Завершение оборванного ответа не показывается как успешное. При ошибке можно повторить тот же запрос без дублирования сообщения.

Ссылка покупки формируется сервером из конфигурации, а не из произвольного URL модели. Модель возвращает `text` и `offerPurchase`; системный промпт задаёт условия мягкого предложения покупки. Поведение языковой модели вероятностное: перед продажами необходимо проверить живые диалоги на вашем ключе. Характеристики, которых нет в конфигурации, не должны додумываться.

## Проверка

`node scripts/test-chat.mjs` проверяет запрос к Gemini с подменённым транспортом: историю и системную инструкцию, ключ в серверном заголовке, ссылку из конфигурации, отсутствие выдуманных ссылок, таймаут, ошибки квоты, неполные/неверные ответы и проверку входных сообщений. Эти тесты не проверяют качество реального диалога с Gemini.

Для ручной проверки с ключом: новичок с 25 минутами дома; «дорого»; «на YouTube бесплатно»; неизвестная длительность/инвентарь; отказ от покупки; травма/беременность; прямая просьба о ссылке; смена цели; сброс во время ответа. Убедитесь, что ответы короткие, вопросы не повторяются и покупка не навязывается.

По умолчанию сайт публикуется приватно для владельца. Перед открытием для широкой аудитории настройте серверную защиту от частых запросов и бюджет/квоты Gemini: эта тестовая версия не содержит распределённого rate limiter или авторизации внутри приложения. Доступ ограничивает приватный хостинг Sites. Сообщения передаются Google для генерации ответа, сервер приложения не сохраняет историю и не пишет тексты сообщений или секреты в логи.

Документация API: https://ai.google.dev/api/generate-content
